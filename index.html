☁️ 클라우드 동기화 (Firebase)
Firebase 미연결 — 로컬 저장 모드
켜두면 이 기기가 인터넷에 연결될 때마다 자동으로 데이터가 클라우드에 저장되고, 로컬 데이터가 지워져도 복구할 수 있어요. 2단계면 충분합니다:
① Firebase 콘솔에서 프로젝트 생성 → "웹 앱 추가" → 나오는 코드 전체 복사
② 아래에 통째로 붙여넣고, 동기화 코드(아무 문자열이나 OK, 여러 기기를 묶을 땐 똑같이 입력)를 정하기만 하면 끝
🔒 붙여넣은 내용은 이 기기의 localStorage에만 저장됩니다.
🔐 앱이 자동으로 익명 로그인을 시도합니다. Firebase 콘솔 → Firestore → 규칙(Rules)에 아래를 꼭 추가하세요:
allow read, write: if request.auth != null; 이 규칙이 없으면 로그인 여부와 상관없이 설정값만 알아도 데이터에 접근할 수 있습니다.

📡 백그라운드 푸시 (앱이 꺼져있어도)
앱을 열지 않아도 폰이 울리는 진짜 푸시예요. 서비스워커는 이미 준비돼 있고, 아래 2단계만 하면 켜져요:
1
Firebase 콘솔에서 프로젝트를 Blaze(종량제) 요금제로 전환 (카드 등록 필요 — 실사용량은 무료 한도 안이라 실제 청구는 거의 0원)
2
Firebase 콘솔 → 프로젝트 설정 → Cloud Messaging → “웹 푸시 인증서”에서 VAPID 키 발급 후 아래에 붙여넣기
백그라운드 푸시 꺼짐
실제로 알림을 “보내는” 서버 쪽 코드(누가 언제 결제일인지 매일 확인하는 부분)는 저장소 /functions 폴더에 준비돼 있어요. 1번을 마치신 뒤 firebase deploy --only functions까지 실행하셔야 실제로 알림이 옵니다.
